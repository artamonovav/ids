# IDS — релизные заметки

Файл объединяет заметки к **0.3.1** и **0.3.0**. Черновой тег `v0.3.0-alpha`
и его draft-релиз устарели — используйте `v0.3.1`.

---

## v0.3.1 — 29 октября 2026

### Главное

**Редактор Markdown в стиле Obsidian.** Тело локализации теперь редактируется
в Live-режиме на CodeMirror 6: разметка отображается сразу, а маркеры (`**`, `#`,
обратные кавычки, скобки ссылок) показываются только тогда, когда курсор попадает
в соответствующий фрагмент. Исходник остаётся настоящим Markdown — декорации
ничего не переписывают, файлы в базе знаний не меняются от открытия и переключения
режимов.

### Редактор

- Режимы: **Live** (по умолчанию), **Исходник**, **Совмещённо**, **Просмотр**.
  Undo/redo и позиция курсора сохраняются при переключении режимов.
- В Live отображаются: заголовки, жирный, курсив, зачёркнутый, инлайн-код,
  ссылки, изображения из `attachments/` и кликабельные чек-листы.
- Клик по чекбоксу переключает `[ ]` ↔ `[x]` прямо в Markdown.
- Палитра дополнена: жирный, курсив, зачёркнутый, инлайн-код, заголовки H1–H3,
  маркированный и нумерованный списки, чек-лист, цитата, таблица, блок кода,
  ссылка, изображение, файл во вложениях, горизонтальный разделитель.
- Горячие клавиши работают в русской раскладке:
  `Ctrl+И` (B), `Ctrl+Ш` (I), `Ctrl+У` (E), `Ctrl+Л` (K), `Ctrl+Shift+Ч` (X).
- Сохранены вставка картинок из буфера (включая fallback WebKit2GTK на Linux),
  drag&drop изображений и вложений.

### Темы оформления

- Переключатель темы в шапке стал выпадающим меню с двумя группами: **Режим**
  (системная / светлая / тёмная) и **Палитра**.
- Добавлены палитры **GitHub**, **Nord**, **Catppuccin** и **Solarized** —
  у каждой светлый и тёмный варианты, поэтому палитра сочетается с любым
  режимом. Стандартная тема сохранена.
- Выбранная палитра запоминается и применяется до первой отрисовки — без
  мигания стандартной темы при запуске.

### Настройки и первый запуск

- Все пользовательские настройки — в одном файле `config.yaml` в папке
  конфигурации ОС, в подпапке `ids`:
  - Linux: `~/.config/ids/config.yaml`
  - macOS: `~/Library/Application Support/ids/config.yaml`
  - Windows: `%APPDATA%\ids\config.yaml`
- В `config.yaml` хранятся путь к текущей папке проекта, профиль (ФИО, email)
  и `recentLimit`. Отдельного `paths.json` больше нет.
- Если путь к проекту пуст, при запуске открывается мастер. Поля мастера
  предзаполняются значениями из конфига.
- В настройках появилась кнопка **«Сброс»**: закрывает текущий проект и снова
  открывает мастер. Профиль и остальные настройки сохраняются, файлы на диске
  не удаляются.
- Автоматическая миграция: путь к проекту переносится из `paths.json` версии
  0.2.9 (`app_data_dir`), профиль — из старого `.tmp/config.yaml` в папке проекта.
  Старые файлы не удаляются.

### Исправления

- Убрано дублирующее поле пути к папке в настройках.
- Исправлена высота редактора: поле ввода и просмотр больше не схлопываются
  в WebKitGTK и скроллятся внутри себя.
- Горячие клавиши форматирования определяются по физической клавише (`e.code`)
  и работают в кириллической раскладке.
- CI обновлён на `actions/checkout@v5` и `actions/setup-node@v5`.

### Ограничения Live-режима

- Таблицы и произвольный HTML в Live показываются как исходный текст —
  для них используйте «Просмотр» или «Совмещённо».
- Картинки ищутся во вложениях текущей локализации по пути
  `attachments/<имя>` или по имени файла.

### Обновление

Обновление с 0.2.9 и 0.3.0 не требует ручных действий: настройки и путь
переносятся автоматически при первом запуске. Формат базы знаний не менялся.

## v0.3.0 — 29 октября 2026

### Главное

Сохранённые локализации стали редактируемыми, настройки вынесены из папки
проекта, добавлены клонирование репозитория и настройка git-идентичности.

### Что нового

- **Редактирование сохранённых локализаций.** Документ открывается в режиме
  просмотра; кнопка «Изменить» включает редактирование, «Отмена» возвращает
  исходные данные. Номер сохранённой локализации заблокирован — он задаёт папку.
- **Уточнение без изменений** создаёт новый файл и сразу открывает его
  в режиме редактирования.
- **Настройки в папке конфигурации ОС** (`config_dir/ids`): профиль и
  `recentLimit` больше не лежат в папке проекта; миграция из `.tmp/config.yaml`
  выполняется при первом запуске.
- **Мастер настройки:** ссылка на git-репозиторий и папка, клонирование
  в пустую папку, выбор ветки.
- **Смена папки проекта без перезапуска** из настроек.
- **Git-идентичность:** если `user.name`/`user.email` не заданы, приложение
  спрашивает их и сохраняет локально в проекте или глобально.
- Git-команды, ходящие в сеть, выполняются в фоне и не блокируют интерфейс;
  `GIT_TERMINAL_PROMPT=0` — при недоступности git сразу возвращает ошибку.

### Безопасность

- Проверка путей в Rust: `join()` запрещает `..`, абсолютные пути и префиксы —
  номер локализации из формы не может вывести запись за папку проекта.
- `git_checkout_pull` отклоняет имена веток, начинающиеся с `-`.
- Добавлены unit-тесты для проверки путей.

### Редактор и интерфейс

- GFM-таблицы и `~~зачёркивание~~` в просмотре; таблицы прокручиваются
  по горизонтали.
- Фиксированная высота редактора (70vh): поле ввода и просмотр скроллятся
  внутри себя.
- Горячие клавиши форматирования: `Ctrl/⌘+B`, `I`, `E`, `K`, `Shift+X`
  с переключением разметки; кнопки палитры используют ту же логику.
- Системные шрифты ОС для интерфейса и моноширинного текста
  (исправлены остатки Next.js-переменных).

### Инфраструктура и платформа

- Удалена веб-версия (Next.js): единственный таргет — десктоп на Tauri 2.
- Проект `ids-desktop` перенесён в корень репозитория; пути в CI, Docker,
  скриптах и документации обновлены.
- Версии Tauri (npm и crates) выровнены, `Cargo.lock` закоммичен —
  сборка воспроизводима.
- Portable-сборка для Windows: данные пользователя теперь указываются как
  `%APPDATA%\ids\config.yaml`.

### Обновление с 0.2.9

Путь к базе знаний и профиль переносятся автоматически. Если папка проекта
не определилась, откроется мастер настройки — укажите папку вручную.
