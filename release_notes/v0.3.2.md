# IDS — релизные заметки

Заметки к релизу **0.3.2**. Предыдущие версии — в `release_notes/v0.3.1.md`.

---

## v0.3.2 — 18 ноября 2026

### Главное

Полировка рабочей области и редактора: продукты на карточках, фильтрация
справочника продуктов по мере ввода, возврат в рабочую область после сохранения,
доброжелательное клонирование в непустую папку, восстановленный фикс
сглаживания шрифта в редакторе на Linux, журнал работы и git, одинаковый
набор кнопок в редакторе сверху и снизу. Четыре новые палитры, починенные
светлые темы и проверка новых версий.

### Рабочая область

- **Продукты на карточках.** На карточках локализаций (и сохранённых, и
  `.tmp`-черновиков) после типа и окружения выводятся чипсы продуктов —
  видно, к каким продуктам относится проблема, не открывая локализацию.
- **Возврат после сохранения.** Сохранение локализации («Сохранить» или
  `Ctrl+S`) теперь автоматически возвращает в рабочую область — карточка сразу
  видна с обновлёнными данными. «Сохранить как черновик» по-прежнему остаётся
  в редакторе.
- **Сортировка «Все»**: локализации идут от самых новых к самым старым —
  по номеру дефекта по убыванию (большие SPAS сверху, детерминированно;
  при равенстве номера — по времени обновления).

### Продукты: ввод и подсказки

- При вводе названия продукта список подсказок **фильтруется по мере ввода**
  (без учёта регистра), а совпадающая часть **подсвечивается**.
- Пока поле пустое — показывается весь справочник `product.yaml`, отсортированный
  по-русски (поведение 0.2.x сохранено).
- Как и раньше, название можно довести руками и нажать Enter, либо выбрать
  подсказку мышкой или с клавиатуры.

### Проект и клонирование

- **Клонирование в непустую папку.** Раньше выбор непустой папки (например,
  `~/prj`) давал ошибку «папка не пуста», хотя руками `git clone` в неё сделать
  можно. Теперь `git_clone` ведёт себя как git: если папка непуста, репозиторий
  клонируется в подпапку `<папка>/<имя-репо>` — имя берётся из ссылки
  (`git@host:org/ids-kb.git` → `ids-kb`), как при `git clone <url>` без явной папки.
- Ветка и открытие проекта идут по фактической папке клонирования; в мастере
  настройки и в «Смене проекта» она подставляется автоматически, а подпись поля
  и результат проверки показывают, куда склонировался репозиторий.
- Ошибка теперь честная: если занята и выбранная папка, и подпапка с именем
  репозитория, сообщение это прямо указывает.

### Исправления

- **Сглаживание шрифта на Linux (WebKit2GTK).** Фикс 0.2.x покрывал только
  textarea, а после перехода редактора на CodeMirror (0.3.1) основной ввод
  текста шёл без него — текст снова мерцал между жирным и нормальным весом.
  Grayscale antialiasing (`-webkit-font-smoothing: antialiased`) и
  `text-rendering: optimizeSpeed` применены к теме CodeMirror: Live-режим,
  «Исходник» и mono-блоки наследуют его целиком.
- Уточнение документации архитектуры: контракт `prepareRepo`, таблица
  Rust-команд (`git_clone` возвращает фактическую папку), известный нюанс
  про сглаживание шрифта.

### Журнал работы и git

- Новый раздел **«Журнал»** в шапке: лог работы приложения и лог выполнения
  команд git, только просмотр.
- Две вкладки с подсчётом записей: **Работа** (открытие проекта, создание и
  сохранение черновиков, синхронизация, запись/удаление файлов, справочники)
  и **Git** (каждая команда: строка запуска, код выхода, stderr при ошибке).
- Кнопки **Обновить** и **Выгрузить** — выгрузка журнала в `.txt` через
  диалог сохранения ОС.
- Журнал хранится вне папки проекта, в папке конфигурации ОС
  (`~/.config/ids/app.log` на Linux), переживает перезапуск и не
  синхронизируется; при превышении ~4 МБ ротируется в `app.log.1`.

### Редактор: набор кнопок сверху и снизу

- Внутри локализации одинаковый набор кнопок теперь и сверху, и снизу:
  **Сохранить**, **Синхронизировать**, **Удалить**.
- **Удалить** — новая кнопка, доступна только у несинхронизированного черновика
  (`.tmp` не попадает в git); сохранённые локализации из редактора не удаляются.
  Удаление — с подтверждением; после удаления открывается рабочая область.
- Кнопки «Изменить», «Отмена» и «Уточнить локализацию» остались в шапке как были.

### TUI-раздел (как opencode/btop, но не терминал)

- Новый раздел **«TUI»** в шапке — рабочая область в терминальной эстетике:
  моноширинный шрифт, панели с бордерами, ASCII-индикаторы
  (`СИНХР [████████░░] 90%`), панель статусов (локализаций, черновиков,
  синхронизация, продукты в справочнике).
- Клавиатурная навигация: `j/k` (и стрелки), `g/G` — начало/конец,
  `Enter` — открыть, `n` — новый черновик, `s` — синхронизация,
  `/` — фильтр, `Esc`/`q` — выход. Мышь работает: клик — выбор,
  двойной клик — открыть; выбранная строка автоскроллится.
- Вкладки «Локализации»/«Черновики» со счётчиками, сортировка и фильтр —
  как в обычной рабочей области. Те же действия store — второй логики нет.
- Работает во всех палитрах (в т.ч. новых) — всё на CSS-переменных.

### Редактор: Live-режим

- **Производительность.** Декорации (скрытие маркеров, стили) теперь строятся
  только для видимой области документа — ввод и прокрутка не тормозят
  на больших локализациях.
- **GFM-таблицы отрисованы** в Live (как в Obsidian): курсор внутри таблицы —
  таблица показывается как исходник для правки.
- **diff-блоки (```diff)** с цветовой индикацией строк: `+` — добавлено
  (зелёный), `-` — удалено (красный), `@@` — заголовок hunk (синий).
  Работает в Live и в «Просмотре», цвета согласованы с тёмной темой.
- Доработки парсера: экранирование (`\*`, `` \` ``), закрывающие `##` в
  заголовках, автолинки `<https://…>`, `***жирный курсив***`, вложенные цитаты
  с отступом по уровню.
- Ссылки показывают URL при наведении (тултип), выполненные задачи зачёркнуты,
  клик по картинке открывает полноразмерный предпросмотр.
- **GitHub-алерты** `> [!NOTE]` / `[!TIP]` / `[!IMPORTANT]` / `[!WARNING]` /
  `[!CAUTION]` — цветные плашки с заголовком в Live и в «Просмотре».
- **Перенос строк как в переписке**: одиночный перенос в конце строки даёт
  разрыв строки в «Просмотре» (remark-breaks) — не нужны два пробела.
- **Подсветка синтаксиса кода** в «Просмотре»/«Совмещённо»: yaml, bash/shell,
  json, js/ts, python, sql, xml, java (ограниченный набор языков —
  ради размера бандла).

### Темы оформления

- **Четыре новые палитры**: **Dracula**, **Tokyo Night** (Day/Night),
  **Rosé Pine** (Dawn/Main), **Gruvbox** (light/dark) — у каждой светлый
  и тёмный варианты, сочетаются с любым режимом.
- **Починена светлая тема по умолчанию на Linux**: она была задана через
  oklch(), который WebKitGTK не поддерживает — переменные отбрасывались и
  интерфейс рендерился «голым». Переведена в hex (эквивалент Tailwind zinc).
- В палитры добавлены цвета графиков (`--chart-*`): раньше они падали в
  невалидный oklch-фолбэк.

### Проверка обновлений

- Автоматическая проверка раз в сессию при запуске: сравнение версии
  приложения с последним релизом на GitHub. Если есть новее — toast
  и подсвеченная версия `vX.Y.Z → vX.Y.W` в футере (клик открывает
  страницу релизов).
- В настройках — секция «Обновления»: кнопка «Проверить обновления»
  и переход на страницу релизов.
- Проверка идёт через публичный GitHub API прямо из WebView — без токенов
  и сторонних updater-сервисов; офлайн и лимиты API глушатся тихо.

### Обновление

Обновление с 0.3.0/0.3.1 не требует ручных действий: формат конфига и базы
знаний не менялся. Папка проекта определяется из `config.yaml` как раньше.
