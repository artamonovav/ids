# IDS — релизные заметки

Заметки к релизу **0.3.3**. Предыдущие версии — в `release_notes/v0.3.2.md`.

---

## v0.3.3 — 19 ноября 2026

### Главное

Полировка списков и навигации: TUI стал резиновым и получил шторку
предпросмотра Markdown, графический режим — табличное отображение
с сортировкой по колонкам и пагинацией, вкладка «Последние» упразднена,
«Обновлено» в списках теперь берётся из даты сохранения записи,
индикатор синхронизации сверяется с реальным git.

### Рабочая область

- **Вкладка «Последние» удалена.** Осталось две вкладки: «Все» (по умолчанию)
  и «Черновики». Настройка «Локализаций в „Последние"» из профиля убрана
  за ненадобностью.
- **Табличное отображение** (фича-флаг в настройках, «Режим работы»): плотная
  таблица вместо карточек — номер (+файлы/статус), тип, окружение, продукты,
  симптом, автор, обновлено. Поиск и фильтр по типу работают.
  Флаг недоступен при включённом TUI-режиме.
- **Поведение предпросмотра — как в TUI**: клик по номеру открывает
  локализацию, клик по остальным полям строки — выбор + шторка
  предпросмотра Markdown справа (по умолчанию 2/3 ширины, перетаскивается,
  закрытие крестиком или кнопкой «Предпросмотр»). Двойной клик по строке —
  открыть.
- **Сортировка таблицы по колонкам**: клик по заголовку сортирует
  по возрастанию/убыванию (стрелка ▲/▼). Строки сортируются по-русски,
  номер и дата — по убыванию по умолчанию.
- **Пагинация страниц** вместо «показать ещё»: `‹ Назад · Стр. X из Y (N) ·
  Вперёд ›`. Смена фильтра/вкладки возвращает на первую страницу.
- **Дата сохранения.** В frontmatter появилось скрытое поле `saved_at` —
  заполняется при каждом сохранении в базу знаний (в форме не показывается).
  «Обновлено» в списках берётся из него; в старых записях без поля — как
  раньше, по времени изменения файла.

### TUI-режим

- **Резиновая ширина**: TUI не ограничен центральной колонкой, список
  использует всю ширину окна; колонки адаптивные (маловажные скрываются
  на узких).
- **Шторка предпросмотра** (`v` или кнопка «предпросмотр»): справа рендерится
  Markdown активной записи — те же плагины, что в Просмотре редактора
  (алерты, таблицы, diff-блоки, картинки из вложений). Ширина по умолчанию
  2/3 окна, перетаскивается, следует за выбором в списке.
- **Заголовок колонок** в списке (Номер / Тип / Окр. / Продукты / Стат. /
  Симптом), залипает при прокрутке.
- Клавиатурная навигация: `j/k` (и стрелки), `g/G` — начало/конец,
  `Enter` — открыть, `n` — новый черновик, `s` — синхронизация,
  `d` — удалить черновик (только вкладка «Черновики», с подтверждением),
  `v` — предпросмотр, `/` — фильтр, `Esc`/`q` — выход (Esc сначала закрывает
  предпросмотр). **Backspace в карточке** возвращает на список (когда фокус
  вне полей ввода; в режиме редактирования — не теряет правки).
- **Tab** обходит элементы управления (вкладки, фильтр, строки; фокус строки
  синхронизирует выбор). Мышь: **клик по полю номера** открывает локализацию,
  **клик по остальным полям** — выбор + шторка предпросмотра; выбранная
  строка автоскроллится в зону видимости.

### Настройки

- Секции «Режим работы» и «Вид» объединены в одну — **«Режим работы»**:
  автономный режим, TUI-режим, табличный список, размер текста.
- **Размер текста**: масштаб интерфейса 85/100/115/130% (85% и так далее —
  хранится в `config.yaml`, применяется до первой отрисовки).

### Индикатор синхронизации стал честным

- `.tmp`-черновики больше не держат «жёлтый» вечно — они gitignored,
  синхронизировать в них нечего.
- После открытия проекта, фонового pull и синхронизации статус сверяется
  с реальным состоянием git: незакоммиченные файлы (`git status --porcelain`
  без `.tmp`) и неотправленные коммиты (`rev-list @{upstream}..HEAD`).
- Автосохранение черновика, переименования и удаления `.tmp` статус не
  трогают; изменения базы знаний ставят «жёлтый» мгновенно, как раньше.

### Сглаживание шрифтов — глобально

- Фикс сглаживания 0.2.x покрывал только textarea, затем (0.3.2) ещё и
  CodeMirror — но на Ubuntu 22.04 страдал весь интерфейс: subpixel
  antialiasing мерцает весом текста (жирный ↔ нормальный) при любой
  перерисовке. Grayscale AA (`-webkit-font-smoothing: antialiased`) и
  `text-rendering: optimizeSpeed` теперь заданы **глобально** в `globals.css`
  для всего приложения.

### Рендеринг на Ubuntu 22.04

- На Ubuntu 22.04 (WebKitGTK ~2.40) окно приложения могло оставаться пустым
  или прозрачным — вместо UI просвечивал рабочий стол. Причина: DMABUF-рендерер
  WebKitGTK, ломающийся на этой версии. Теперь на 22.04 он **отключается
  автоматически** (24.04+ не затронуты — там рендерер работает и быстрее).
- Ручное управление: `IDS_ENABLE_DMABUF=1` — принудительно включить на 22.04,
  `IDS_DISABLE_DMABUF=1` — принудительно выключить на любой системе.
- Диагностика: журнал `~/.config/ids/app.log` на проблемной машине показывает,
  дошло ли приложение до инициализации (`инициализация проекта`, `открыт
  проект`) — если строк нет, окно зависает до установки веб-просмотра.

### Обновление

Обновление с 0.3.2 не требует ручных действий: `config.yaml` и база знаний
совместимы; `recentLimit` в старых конфигах игнорируется. Поле `saved_at`
появляется в записях после первого пересохранения.
